# 界面层级与细节

- 用内容之间的关系确定字号与字重：页面标题高于章节或主要问题，章节或主要问题高于它的评分、说明和附属操作。相邻元素不能因为都是“问题”就自动使用同一层级。例如“想法 1”是条目标题，“此时对这句话的相信程度”是它的附属评分，后者更小、更轻。
- 用间距表达归属：标题与正文、问题与输入框靠近；不同模块之间留更多空间。不要对所有相邻元素使用同一间距。
- 必要引导直接显示，扩展引导可以折叠；多句引导尽量逐句换行，避免挤成一段。
- 与文字并排的图标，图案大小跟随旁边文字，同时保留足够大的触控区域。图标形状简单、清晰，状态图标有可读的无障碍描述。
- 操作面板、输入框、卡片及浮层使用圆角；弹窗左右保留空间。点击反馈使用应用配色，不使用系统默认的黄色背景。
- 内容较多时保持可滚动；键盘弹出和屏幕旋转后，当前内容及主要操作仍可访问。底部只放与当前步骤直接相关的操作。

## 内容层级

同一角色在首页、七步日志、探索弹窗、方法卡片和回顾页使用同一字号、字重和段内行距。先判断内容与上级的关系，再选择角色；不要因为一句话带问号就自动放大。这里的“行距”同时包括文字内部的行距和页面中相邻组件之间的距离，两者都必须检查。

| 角色 | 例子 | 字体 | 额外行距 | 组件自身上 / 下内边距 |
| --- | --- | --- | --- | --- |
| 页面标题 | 正向重构、探索想法 | 24sp 粗体 | 2dp | 22 / 4dp |
| 弹窗标题 | 识别认知歪曲、检验证据 | 20sp 粗体 | 2dp | 由统一标题栏提供 |
| 章节标题 | 刚才记录的想法、可以尝试的方法、情绪的变化 | 17sp 粗体 | 2dp | 16 / 4dp |
| 条目标题 | 想法 1、焦虑词组、方法名称 | 16sp 粗体 | 2dp | 10 / 4dp |
| 当前问题 | 可能有什么益处、方法练习的问题 | 16sp 粗体 | 4dp | 12 / 4dp |
| 填写内容 / 回顾正文 | 用户填写的情境、回应 | 16sp 常规 | 4dp | 0 / 8dp |
| 附属评分名称 | 想法的相信程度、情绪强度 | 14sp 常规、弱化色 | 2dp | 6 / 2dp |
| 引导与补充说明 | 问题下的思考提示、方法简介 | 14sp 常规、弱化色 | 4dp | 4 / 8dp |
| 简短预览 | 重构页回看的情绪和想法 | 14sp 常规 | 2dp | 2 / 2dp |
| 进度与元信息 | 第几步、日期、评分表头 | 13sp 常规、弱化色 | 2dp | 4 / 4dp |

评分数字统一为 16sp 粗体，右对齐；AI 来源提示保留蓝色以区分来源。图标的图案大小跟随并排文字，触控区域独立保持足够大。

## 组件之间的距离

先确定两个组件是不是同一组，再确定最终可见间距。相邻组件各自的 padding、margin 和额外 spacer 都要计入，不能只看其中一个值。输入框、滑块、按钮和卡片也遵守此规则。

| 关系 | 例子 | 约定 |
| --- | --- | --- |
| 标题接所属内容 | 问题 → 输入框、章节 → 列表 | 紧密，约 4–8dp |
| 同一条目内连续填写 | 想法输入框 → 相信程度标签 | 输入框下 2dp 加评分行上 6dp，总计 8dp |
| 标签接控件 | 相信程度标签 → 滑块 | 不加额外 spacer；保留控件自身 48dp 触控高度 |
| 不同问题 | 一个文本框 → 下一个问题 | 输入框后留 16dp，再由下一个问题提供自身顶部间距 |
| 不同条目 | 想法 1 → 想法 2、方法卡片之间 | 至少 12dp，可用分隔线加强区分 |
| 不同章节 | 一组内容 → 下一章节 | 大于组内间距；额外 spacer 与章节标题自身上边距合计检查 |

组件间距按“所属关系”决定，不按控件类型一刀切。同一角色的段内行距保持一致，但组件之间可以因为归属不同而采用不同距离。
