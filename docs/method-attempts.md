# 方法记录

## 1.5 范围

六种方法：检验证据、双重标准法、灰度思考、语义法、重新归因、定义用词。提示在 `ThoughtMethods.java` 中维护，是独立编写的简化自助引导。

每种方法有三个思考步骤，以及一个回应与评分步骤。思考笔记可留空，例子可折叠。最终保存需要回应、回应相信程度和原想法的当前相信程度；不会要求分数降低或回应相信程度达到特定值。

## 保存约定

- 沿用 `attempts` 数组保存数据。新版本每条想法的每种方法只有一份主记录：重复选择方法先按稳定方法 ID 查找，存在则继续或查看，不新建。
- 尝试包含稳定方法 ID、名称、原想法快照、创建时间、当前步骤、三段笔记、回应、开始/结束相信程度、回应相信程度及完成状态。
- 开始评分取最近的原想法评分，可自行调整；不覆盖日志最初的评分。
- “保存并退出”保留草稿，重新进入从原步骤继续；“下一步”推进当前练习。
- “换个方法”保留当前内容并标记 `noHelp`（暂未奏效），直接打开其他方法，无需填写完回应和评分。
- 已完成和暂未奏效的记录只读，不提供同方法的新一轮尝试入口。
- 旧版已存在重复方法记录时，最近创建的一份为主记录，其他保留到旧版记录区；不删除旧数据。
- 最新完成的尝试更新想法概览的回应、相信程度和结束评分。开始新草稿不抹掉已完成结果。
- 原版本自由探索首次打开方法列表时归档一次；旧字段继续保留，旧日志不会因升级而删除。
- 日志回顾和文本导出均包含尝试历史，包括尚未完成的草稿。
