# 焦虑相关方法的内容与实现审查（1.27）

本次实现此前讨论的焦虑相关方法，不是一次补齐全部 50 种。原有六种保留，新增十种，共十六个可选方法。悖论双重标准法暂时撤下，待后续改为用户扮演自己与朋友、可持续追加对话的聊天窗口；本轮不实现聊天。暴露的不同媒介不当成新增“50 种”编号来统计。

## 资料依据与核对边界

- [Burns 的 50 种方法目录，上半部分](https://feelinggood.com/2018/06/18/093-fifty-ways-in-fifty-minutes-part-1/)与[下半部分](https://feelinggood.com/2018/06/25/094-50-methods-in-50-minutes-part-2/)提供方法名称与分类。
- [作者官网的 50 种方法概览 PDF](https://feelinggood.com/wp-content/uploads/2017/10/cff19-overview-of-50-cbt-techniques-version-of-2005.pdf)。
- [Burns 2021 讲义](https://webinars.jackhirose.com/wp-content/uploads/2021/12/May-5-Burns-Handout.pdf)的 PDF 第 55 页是目录，第 56–58 页是认知歪曲对应表（讲义内部页码 14–17）。用于核对名称、分组及推荐匹配。
- [作者的方法背景介绍](https://feelinggood.com/science-behind-t-e-a-m-therapy/)说明实验法要设计并实施实验，而非仅想出反面证据。
- 作者另有[悖论双重标准法介绍](https://feelinggood.com/2018/04/16/084-paradoxical-double-standard-technique/)与[恐惧幻想介绍](https://feelinggood.com/2018/04/30/084-role-play-techniques-part-4-feared-fantasy/)。

初次实现时开发环境不能联网，可直接核对的是此前会话保存的作者目录、2021 讲义相关页及官网的方法背景摘录。下面的步骤是围绕方法核心操作独立编写的自助流程，步骤数属于产品组织方式，不是原书原句或作者规定的固定问卷。**十种新增方法的详细流程仍需逐项对照完整官方指导复核；不能把本轮提问精简描述成已完成原书或各专门说明的逐项核验。**

## 提问原则

先掌握方法的目的、对象、前提、核心动作和收尾，再安排问题，步骤数不预先固定。每个问题只承担一个主要任务，并与常驻说明完整交代条件、角色和判断依据，不能没头没尾。简洁不能牺牲完整性。事件、想法、预测、计划、实际结果和最终回应分开记录，不通过问题暗示结果必须积极或焦虑必须降低。必要边界常驻，前面记录按需回看。新方法的问题与说明全文由运行时代码导出在 [ai-prompts-1.27.md](ai-prompts-1.27.md)。

## 各方法的操作链

以下数量是内容步骤数，均另有一个最终确认与评分页。新增方法不是套用原有三问。

| 方法 | 步骤 | 操作链与保留的重点 |
| --- | --- | --- |
| 成本收益分析 | 5 | 明确一项分析对象 → 保留它的好处 → 保留它的代价 → 按重要程度分配总计 100 分 → 用户决定保留或调整。利弊不等于真假，不按条数计票。 |
| 实验法 | 5 | 可检验的预测 → 安全的实验行动 → 事先约定结果标准 → 实施并记录事实 → 比较预测与实际并形成理解。未实施不能编造结果。 |
| 调查法 | 5 | 明确关于他人看法的判断 → 有限且合适的调查对象 → 中立问句 → 实际答复 → 结合样本局限重新理解。不是反复寻求保证。 |
| 恐惧幻想 | 4 | 假想批评者说出害怕的评价 → 自己直接回应 → 继续或交换角色练习 → 区分‘别人真实想法’与‘如何面对评价’。不能把假想台词当真实证据。 |
| 现实暴露 | 6 | 安全但被回避的情境 → 具体危险预期与回避方式 → 难度序列 → 本轮接近计划 → 真正实践 → 比较预期与经历并回应担心。 |
| 想象暴露 | 5 | 担忧画面 → 具体想象片段 → 接近片段的安排 → 实际想象过程 → 对面对担忧的理解。属于认知暴露；不以换成好结局抵消担忧，不把想象当事实。 |
| 反应预防 | 6 | 触发情境 → 用于消除不安的重复反应 → 自愿减少反应的计划 → 实际应对冲动 → 观察变化与仍不确定处 → 留下发现并决定是否再练。检查是否转用了其他仪式。 |
| 羞耻攻击练习 | 4 | 害怕的评价 → 无害小尴尬行动 → 实际经历 → 比较预期与经历并回应原要求，检验尴尬与人格价值的联系。不是故意冒犯别人或索求羞辱。 |
| 微笑与问候练习 | 4 | 预期反应 → 自然且有限的接触计划 → 实际回应 → 比较预测与经历。不以每个人都回应为完成条件。 |
| 自我披露练习 | 5 | 担心被知道的内容 → 可信对象与分享边界 → 自己愿意说的真实话 → 实际表达与回应 → 重新理解隐藏自己的要求。选择和隐私范围由用户决定。 |

## 提问精简

本轮只合并明显重复的内容：实验法原第 5、6 题，现实暴露原第 6、7 题，以及羞耻攻击练习原第 4、5 题，均合为一次比较结果并形成回应；恐惧幻想原第 1、2 题合为假想批评者直接说出害怕的评价。预测与实际结果仍分开记录，调查对象与问句、想象片段与练习安排等不同任务继续保留。

悖论双重标准法不再作为方法条目出现在方法列表、AI 候选或提示词导出中，已有记录通过保存的题目快照继续回顾。其他方法的已有草稿与历史也沿用原题目，不按精简后的步骤重新解释答案。

## 暴露的范围

目录 #36 的渐进暴露和集中暴露共用“现实暴露”记录。渐进练习支持按难度排列行动、选择本轮并保留多轮结果；集中暴露只记录用户与专业人员已有的计划，不自动安排最难场景或身体诱发。必要防护不取消，真实危险和无法承受时可以停止，不以焦虑归零为完成条件。

认知暴露另列“想象暴露”；人际暴露由调查、羞耻攻击、问候、自我披露等具体练习承接。虚拟暴露是媒介：可记录用户利用自备模拟材料所做的练习并区分与现实的结果，本 App 没有内置 VR 场景或模拟引擎。不扩展到这次未讨论的创伤记忆重写、调情、拒绝练习等其他方法。

## 保存与 AI 边界

详见 [method-attempts.md](method-attempts.md)。真实行为的观察步骤无 AI 入口，写入层也拒绝此类任务；实践确认和评分由用户自己操作。计划尚未执行时不能完成行为练习。反思与角色练习可使用 AI，但保持假想角色和材料边界。

最终确认页可在同一主记录下保存本轮并继续下一轮，已保存的轮次不会覆盖。只有结束整个方法探索才更新想法概览。原有完成记录、旧草稿和字段继续兼容。
