# 页面提问审视

范围：七步日志、想法探索弹窗、六种方法的三步提问。检查每个提问是否有明确对象、是否符合方法重点，以及一个标题是否只问一件事。这里的中文问题是独立编写的引导，不是《Feeling Great》原书译文。

## 依据与取舍

- [Burns 对 Daily Mood Log 的说明](https://feelinggood.com/2026/06/22/507-mastering-the-daily-mood-log-small-details-life-changing-results/)强调一个具体时刻、当时的情绪、简短的自动想法，以及真实且与原想法有关的回应。
- [Burns 的 Positive Reframing 案例](https://feelinggood.com/2022/07/25/302-why-am-i-like-this-live-work-with-nazli-part-2-of-2/)依次问感受或想法为何可以理解、可能有什么益处、可能体现什么可贵品质或核心价值。这里探索的是负面感受或想法中的可取之处，不是为事件找好处。
- [Burns 对 Magic Dial 的讲解](https://feelinggoodinstitute.com/webinar/rapid-recovery-from-anxiety-and-shame)是在保留重要价值的同时，选择个人愿意保留的感受强度；目标不必为零。
- [Burns 的方法概览](https://feelinggood.com/science-behind-t-e-a-m-therapy/)描述了检验证据、重新归因和灰度思考的核心方向；[双重标准法示范](https://feelinggood.com/2018/04/16/084-paradoxical-double-standard-technique/)强调对自己与朋友采用的标准；[定义用词讨论](https://feelinggood.com/2024/07/31/406-do-you-have-a-self/)强调检验笼统的人格标签，而非寻找相反的好标签。[作者的方法目录](https://feelinggood.com/2018/06/18/093-fifty-ways-in-fifty-minutes-part-1/)列出其余方法名称。作者的公开文字并未给这里每一步提供固定的三问模板，因此方法练习仍是按其重点编写的自助问题。

## 七步流程

| 位置 | 审视结果与处理 |
| --- | --- |
| 具体情境 | “发生了什么？”有页面上下文，补充说明要求一个具体时刻和可观察的事，保留。 |
| 情绪 | “此刻有哪些感受？”由说明限定为回想刚才情境时的当前感受，并有 0–100 的评分说明，保留。 |
| 自动想法 | “脑海里闪过什么？”对象含糊，改为“脑海里出现了什么想法？”。补充说明区分想法与事件。 |
| 正向重构 | 旧提问“可能有什么益处？”没有指出谁的益处；品质提问过长。依 Burns 案例按“为何可以理解 → 可能起什么作用 → 可能体现什么可贵之处”排列。目标、后果和他人评价只作线索，不直接当作品质。想不到时可留空，不迫使用户编造正面解释。 |
| 魔法刻度盘 | 保留假设情境与“自己愿意保留多少感受”的一个核心问题；折叠引导改为“目标强度怎么选？”。不把目标分数写成预测或治疗要求。 |
| 探索想法 | 先识别可能的认知歪曲，再选方法。步骤标签虽不是问句，但任务明确；可只探索部分想法。 |
| 重新评估 | “现在，感觉如何？”对应再次回想同一情境后的评分；分数可升、降或不变，保留。 |

## 问题、说明与输入框的层级

方法练习与正向重构采用“主要问题 → 常驻补充说明 → 文本框”的顺序。问题为 16sp 加粗，说明为 14sp 灰色；说明到文本框外框为 8dp，文本框内部另有 14dp 上内边距。带 AI 按钮的提问保留 48dp 点击区，但缩小了短标题与说明之间因按钮高度造成的视觉空隙。正向重构的必要解释现在常驻显示，不再只依赖输入框占位文字。

## 六种方法

每行按练习的三个步骤排列。标题只问当前最主要的一件事；条件、例子和证据提示放在标题下的补充说明中。换方法的操作只在方法练习第一页提示一次，不在各题重复。

| 方法 | 官方说明中的重点 | 三个主要问题 |
| --- | --- | --- |
| 检验证据 | 检查原想法的证据，而不是预设它必定错误 | 哪些具体事实支持这句话？／哪些事实不支持这句话？／根据这些证据，原想法有多准确？ |
| 双重标准法 | 比较对自己和对朋友的标准，并尝试公平地对待自己 | 如果朋友有同样的想法，你会对他说什么？／你对自己和朋友用了不同的标准吗？／你对朋友说的话，哪些也适用于自己？ |
| 灰度思考 | 把非此即彼的判断放回连续的具体程度 | 原想法把事情分成了哪两个极端？／两个极端之间还有哪些可能？／怎样描述这次表现更贴近实际？ |
| 语义法 | 检查僵硬要求的语言，并更准确地表达愿望与责任 | 原想法里有哪些僵硬的要求？／这些要求是事实规则，还是强烈的愿望？／怎样把这些要求说得更准确？ |
| 重新归因 | 看到问题由多个因素促成，避免把责任全压在一人身上 | 你现在把问题的原因主要归在谁身上？／还有哪些因素促成了这个问题？／怎样更公平地看待各方的责任？ |
| 定义用词 | 检验“失败者”等笼统标签是否有清楚且能验证的含义 | 原想法里哪个标签最刺痛你？／这个标签的定义经得起检验吗？／原想法中的标签还成立吗？ |

“定义用词”的第三步过去主要要求不用标签描述事件，更接近“具体化”方法；现在先问标签是否还成立，再在补充说明中建议必要时描述具体行为。所有方法的笔记仍可留空，填写过的内容不会因提问文字调整而删除。
