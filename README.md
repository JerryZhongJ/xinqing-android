# 心晴 · 情绪日志

中文原生 Android 自助情绪日志，参考 David D. Burns 的《Feeling Great》及作者公开的 Daily Mood Log 方法。独立开发，非官方产品；不构成诊断或治疗。

## 当前版本 1.25

- 记录、想法和方法状态使用完成、编辑中、待探索、暂未奏效等图标；长按可查看文字说明，读屏也会播报状态。
- 页面、弹窗、章节、条目、问题、评分和引导采用统一的字体与行距层级；回顾页也按这些层级展示。
- 弹窗采用圆角并在屏幕两侧留白；方法练习三点菜单也采用圆角和绿色系点击反馈。上一步与下一步固定并排。
- 字体层级按内容的从属关系设置：主要问题醒目，条目内的评分标签更小、更轻；多句引导按句换行，同排图标随邻近文字调整尺寸。
- 七个独立步骤：具体情境、情绪、自动想法、正向重构、魔法刻度盘、探索想法、重新评估。
- 关键思考引导常驻，扩展问题默认折叠；固定示例已移除，可主动向 AI 请求贴合当前情境的简短帮助。
- 正向重构按已记录的情绪/想法、益处、重视的品质、理解原因排序；理解原因仍可选。益处和品质各有独立 AI，不把事件好处或后续反驳写入重构。
- 情绪与想法的初始评分统一为开始练习时回想同一情境的感受和相信程度；结束时再次回想并评分。
- 情绪分为十组，每组四个提示词，共用一项强度评分，初始为 0%，无需勾选。
- 正向重构列出前面的非零情绪及全部想法，提示思考感受的原因、益处与反映的品质。
- 魔法刻度盘独立设置非零情绪的目标。
- 自选本次探索的想法，记录认知歪曲、事实与更平衡的回应。
- 支持探索多条想法，点击列表中的某条想法，在弹窗中填写认知歪曲、回应和相信程度；各条数据独立保存。
- 探索分为“识别认知歪曲”和“选择方法”两个面板，前者用继续进入后者。先按作者公开对应表对已实现方法做默认排序；点击 AI 后再按 AI 建议排，并展示理由。匹配分仅内部使用，不显示。
- 点击完成本次探索后显示删除线和已探索状态；部分填写显示探索中。稍后继续保留草稿，已完成项可重新打开修改或标记未完成；删除线只表示完成本次练习。
- 方法练习提供常驻思考问题及笔记回顾，说明新旧想法相信程度独立评分，低相信程度也能保存。
- 六种方法：检验证据、双重标准法、灰度思考、语义法、重新归因、定义用词。每种方法为三步思考和一步回应/评分，思考笔记可留空。
- 方法第三步整合为最终回应，第四步直接复用、确认和评分，支持返回修改，无需重复输入。旧版第三步笔记会在回应为空时带入。
- 每条想法的每种方法只提供一份记录。重复点击继续原草稿或查看结果，不新增尝试。方法没帮助时直接换一种，原内容保留并标为暂未奏效，不要求先完成表单。
- “下一步”推进练习，“保存并退出”保留当前草稿，“换个方法”标记暂未奏效并返回方法列表。最新完成的回应更新日志概览。
- 旧版本同一方法的重复记录不删除：最近一份作为主记录，其余收在旧版保留记录中。
- 原版本的自由探索首次进入方法列表时保留为历史记录。回顾和文本导出包含全部方法尝试及草稿。
- 认知歪曲以自动换行的标签按钮多选，选中高亮，再点取消；上方统一的问号入口集中展示全部解释。AI 选出的歪曲及理由列在标签区下方，手动取消的项注明未选中，方便回看理由。
- 标签上下内边距为 4dp，最小高度为 32dp；问号紧随认知歪曲标题，AI 入口保持右对齐。
- 页面间距按章节、标题、正文与输入框分层；问题紧接填写区，输入框后保留更大间距。状态用彩色图标区分，AI 推荐用蓝色提示块区分。
- 探索对话框在旋转时保持当前 Activity 和填写状态，键盘弹出时按可见窗口高度缩放内部滚动区域；第七步只重新评估情绪，想法在方法练习中评分。
- 顶部返回和系统返回统一提供保存并退出、继续填写、删除日志；删除需二次确认。想法通过垃圾桶图标移除，移除前确认。
- 想法输入页仅保留一个编号标题，各条之间有分隔线与留白。
- 回顾页底部固定提供完成按钮，返回日志列表。
- 情绪词改为空格分隔，评分右对齐。中途不反复展示初始评分，总结时才比较前后；探索完成的想法显示最新评分。
- AI 按钮使用无边框、无底色的 AI 矢量字样，保留 48dp 点击区域及长按说明；请求时原位转圈，可再次点击取消，不弹出等待窗口。切页或退出会取消未完成请求。
- AI 图标缩小，并与对应问题同排右对齐，位于填写区域上方。删除日志、移除想法和移除密钥统一使用红色，确认按钮也标红。
- 练习底部固定显示上一步与下一步或完成按钮，保存退出、换方法在右上角圆角菜单中。
- 第七步重新评估情绪并记录下一步行动；原想法相信程度在方法练习结束时评估。
- 自动保存草稿、继续编辑、历史回顾、删除与导出文本。
- 无账号、无分析服务；不求助 AI 时可以离线完成日志。只有主动点击 AI 求助才发送当前情境及相关字段给 DeepSeek。数据保存在应用私有空间，关闭系统备份；卸载或清除数据会删除日志。导出文件是明文。

评分范围为 0–100；初始情绪默认 0%，目标、练习后及想法评分未操作时显示未评估。方法尝试的开始评分沿用最近记录，可自行调整。完成日志不代表症状已经改善，用户可以只探索部分想法。正向重构仍为整篇日志共用，不是逐项重构。旧版本日志保留原有内容，步骤位置自动映射到七步流程。

界面使用 Java 和 Android 原生 View 控件，无第三方 UI 框架。统一了字体、输入框边框、评分数字对齐、点击反馈及主次操作样式。

返回、连接设置、删除和更多操作使用 Lucide 转换的 Android VectorDrawable，按设备密度渲染，图案随并排文字调整尺寸、点击区域保持 48dp。桌面使用矢量前景的自适应图标。Lucide 的 ISC/MIT 许可证随 APK 包含在 `res/raw/lucide_license.txt`。

AI 辅助使用简洁的矢量 AI 字样；非首页返回键位于屏幕左侧，箭头可见边缘距屏幕约 17dp，使用 `<` 形矢量箭头，正文仍保留 22dp 留白。

## 构建与安装

运行环境：JDK 17、Android SDK Platform 34、Build Tools 34.0.0，以及 zip 命令。

```bash
bash build.sh
```

SDK 路径优先读取 `ANDROID_HOME`，其次 `ANDROID_SDK_ROOT`，默认 `$HOME/Android/Sdk`。

产物：`build/xinqing.apk`，支持 Android 8.0 及以上。脚本使用本地 SDK，构建无需下载 Gradle 依赖。APK 使用自动生成的开发签名，仅供开发体验；保留 `build/debug.keystore` 才能持续覆盖安装并保留原数据。

也可以通过 Android Studio 打开根目录，使用 Gradle 工程。首次同步需要下载 Android Gradle Plugin 8.5.2，使用 Gradle 8.7 和 JDK 17。仓库未附带 Gradle Wrapper，此路径尚未验证。

设备连接后的安装命令：

```bash
adb install -r build/xinqing.apk
adb shell am start -n cn.xinqing.journal/.MainActivity
```

## 按需 AI 辅助

所有实际 prompt 全文和发送上下文已从运行时代码生成：[ai-prompts-1.24.md](docs/ai-prompts-1.24.md)。所有方法共用当前问题/形成回应指令，由当前问题确定角色和人称；不固定第一人称，也没有双重标准法人称专用分支。方法目的、当前问题及此前问答随请求一起提供。

只有用户主动请求才介入；不要求用户先填写，不设总开关。

1. 想法、正向重构、歪曲识别、方法选择和练习提供图标求助入口；情境和感受页没有 AI。
2. 只发送当前情境及请求相关字段，不上传整个历史。生成内容使用代拟填写的口吻，不面向用户解释或确认。JSON 校验后自动追加到对应字段，原文保留，新内容另起一行；想法新增成条目，歪曲自动补选，方法自动排序并展示理由。评分仍由用户填写。
3. 请求使用 `deepseek-v4-flash`，开启 thinking，`reasoning_effort=low`，`response_format=json_object`，`max_tokens=8192`。预算为推理留出空间，最终填写内容仍受各字段的短文本限制。仅解析最终 `content`，不展示或保存 `reasoning_content`。格式不符不修改日志。
4. 无自动重试，无后台建议，无进入页面即请求。原位转圈时可取消，120 秒总超时，错误后由用户手动重试。
5. 主页的 AI 连接入口管理密钥，不是功能开关。密钥用 Android Keystore 的 AES-GCM 加密后保存在设备私有空间，不进入源码或 APK。已配置密钥不回显。
6. 方法练习按步骤填写当前字段：前两步为思考笔记，第三步及最后确认页为最终回应。每次都携带前面各步的问题与回答和当前已有内容，不覆盖原文。

DeepSeek 官方文档当前说明旧名 `deepseek-v4-flash` 仍可请求，但服务端路由至 V4.1-Flash；开发环境实测返回 `model=deepseek-flash`。不会把它表述成仍在运行旧版 V4-Flash 权重。见 https://api-docs.deepseek.com/quick_start/pricing/ 。

调试密钥只能通过隐藏输入工具 `tools/configure_ai_key.py` 配置到设备；不要放在代码、命令行参数或构建配置里。`tools/probe_deepseek.py` 使用隐藏输入进行单次虚构连通性请求，不读取个人日志。
